Build a modern SaaS-style CRM web application with a UI similar to Privyr CRM.

Tech Stack:
- Frontend: React + Vite
- Backend: Node.js + Express
- Database: PostgreSQL (or SQLite for development)
- Auth: JWT authentication
- Styling: TailwindCSS
- Icons: Lucide React
- State Management: React Context
- Deployment ready

The application is called "Growitate CRM Platform".

IMPORTANT FEATURE:
After login, the user must choose between two separate CRM workspaces:
1. Growitate CRM
2. DeploidX CRM

Each workspace should have completely separate data:
- clients
- notes
- activities
- pipelines
- analytics

So the database must support a field called:
workspace_id
